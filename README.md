House Price Prediction: This project implements a **Linear Regression model** to predict house prices using key property features. It demonstrates a complete machine learning workflow, including data exploration, visualization, model training, and evaluation.

Tech Stack:
-Python
-Pandas, NumPy
-Matplotlib, Seaborn
-Scikit-learn

Dataset:
-Rows: 1460
-Features: LotArea, BedroomAbvGr, FullBath
-Target: SalePrice

Workflow:
-Exploratory Data Analysis (EDA)
-Feature selection and preprocessing
-Train–test split
-Linear Regression model training
-Evaluation using MSE and R² score

Run:
```bash
python main.py
````
Results:
-R² Score: ~0.37
-MSE: ~4.57 × 10⁹

Notes: This baseline model provides a starting point for house price prediction and can be improved using additional features and advanced models.
